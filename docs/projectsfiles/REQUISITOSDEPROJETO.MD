## ISSUES
- CRIAR ISSUES NO GITHUB, NA COLUNA BACKLOG
- QUANDO FOR REFINAR A TAREFA INCLUIR PARA EM REFINAMENTO.
- APOS SER REFINADA, PASSAR PARA REFINADO, E DEPOIS COMPROMETIDO QUANDO JA ESTIVER BEM ELABORADA, COM BASTANTE INFORMAÇÕES PARA O DESENVOLVIMENTO.
- CRIAR AS LABELS DE PRIORIDADE E DEPENDECIAS DE OUTRAS ISSUES OU REQUISITOS.
- SEMPRE QUE FOR DESENVOLVER UMA ISSUE ATRIBUIR AO MEU NOME NO KANBAN DO GITHUB. PASSAR A ISSUE PARA A COLUNA: EM DESENVOLVIMENTO.
- AO FINAL DO DESENVOLVIMENTO DEVERÁ PASSAR A ISSUE PARA EM CODE REVIEW, ONDE DEVERA SER FEITO A REVISAO BEM COMO CRIAR, EXECUTAR E DOCUMENTAR CASOS DE TESTES.
- DEPOIS DOS CASOS DE TESTES TEREM SIDO CONCLUIDAS COM EXITO E TAMBEM NAO CONTENHA NENHUM IMPEDIMENTO A ISSUE DEVERÁ SER PASSADA PARA A COLUNA DE CONCLUIDA.
